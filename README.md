## Описание
Данный проект создаётся в рамках обучения курса "Python-разработчик" онлайн-университета цифровых профессий SkyPro.
Это виджет, который показывает несколько последних успешных банковских операций клиента.

### Статус проекта:
В разработке.

Реализованы следующие модули:
- Модуль `masks` - содержит функции по наложении маски на номера банковских карт и счетов;
- Модуль `widget` - содержит функции:
  - наложение маски на номера, используя функции из модуля `masks`;
  - получение даты из строки даты-времени формата ISO 8601;
- Модуль `processing` - содержит функции по обработке списка операций;
- Модуль `generators` - содержит функции-генераторы для получения из списка транзакций списка транзакций определённой
валюты или списка их описаний, а так же генератор номеров банковских карт.

# Использование

Модуль `generators`:

1. Функция `filter_by_currency`: отфильтровать список транзакций по коду валюты.

Пример использования указан в файле тестов `test_generators.py` в функции `test_filter_by_currency`.
Списки в тестах указаны в файле `conftest.py`:
- `transaction_list` - исходный список транзакций;
- `transaction_list_filtered_by_rub` - отфильтрованный список транзакций по коду валюты "RUB";
- `transaction_list_filtered_by_usd` - отфильтрованный список транзакций по коду валюты "USD".

2. Функция-генератор `transaction_descriptions`: получение генератора описаний транкций из списка.

Пример использования указан в файле тестов `test_generators.py` в функции `test_transaction_descriptions`.
Списки в тестах указаны в файле `conftest.py`:
- `transaction_list` - исходный список транзакций;
- `transaction_description_list` - список описаний транзакций, который генерирует функция-генератор из
`transaction_list`.

3. Функция-генератор `card_number_generator`: получение генератора номеров банковских карт в указанном диапазоне.

Функция-генератор принимает на вход границы диапазона чисел - номера карт:
- Минимально допустимое значение = `0`;
- Максимально допустимое значение = `9999999999999999` (16 цифр `9`);
- Левая граница должна быть не больше правой границы диапазона;
- При указании левой и правой границы одинаковым числом - будет выведен список с одним номером карты.

Пример использования указан в файле тестов `test_generators.py` в функции `test_card_number_generator`.
Списки в тестах указаны в файле `conftest.py`:
- `card_numbers_16_to_21` - список номеров карт от `0000 0000 0000 0016` до `0000 0000 0000 0021`;
- `card_numbers_5_last_to_max` - список номеров карт от `9999 9999 9999 9995` до `9999 9999 9999 9999`.
